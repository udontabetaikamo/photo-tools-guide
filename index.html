PhotoMapper3 使い方ガイド

PhotoMapper3 は、写真フォルダを読み込むだけで Exif 情報を抽出し、地図上にクラスタ表示できるオールインワンの住宅写真記録ツールである。

1. ツールを開く

▶ PhotoMapper3 を起動

ブラウザのみで動作し、外部サーバーへ画像を送信しないため、行政利用でも安心だ。

2. 写真フォルダを選択

  1. 「画像フォルダを選択」ボタンをクリック。
  2. スマホやカメラで撮影した写真が入ったフォルダを指定。
  3. Exif に含まれる 位置情報・撮影日時 を自動抽出する。

3. クラスタリング半径を調整

初期値は 0.05 km（50 m）。近接写真をまとめたい場合は値を大きく、細かく分けたい場合は小さく設定し、「クラスタ適用」を押す。

4. 写真を確認

マーカーにはクラスタ内の写真枚数が表示される。クリックでギャラリーが更新され、写真を一括閲覧できる。

5. JSON でエクスポート（任意）

「JSON ダウンロード」を押すと、fileName / latitude / longitude / dateTime を含む photo-database.json を保存できる。自治体 GIS 連携やバックアップに利用可能である。
